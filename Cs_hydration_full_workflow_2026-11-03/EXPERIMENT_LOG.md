# Единый научный дневник — Cs⁺(H₂O)ₙ, n = 4–14

**Состояние на момент подготовки:** входные данные и проверяемый код готовы, **реальных вычислительных результатов Cs⁺ нет**. Отдельные тестовые данные не считаются научными результатами.

## 1. Постановка и методика

Исследуется ряд Cs⁺(H₂O)ₙ с n = 4–14, по 100 стартов на состав. Цель — изучить влияние n на энергию, КЧ, ориентацию воды и появление второй оболочки. При одинаковом заряде +1 Cs⁺ соответствует крупному пределу ряда Li⁺ → Na⁺ → K⁺ → Rb⁺ → Cs⁺.

**Метод:** GWH (`zyz`, WaterCharges; опорные точки 3,33 Å) → свободная GFN2-xTB/ALPB(water), заряд +1, синглет → `tight` → Hessian → проверка 3N−6 внутренних частот (должны быть положительными) → CoCoS (проверяемый `--CritFreq 125` см⁻¹; сравнение с 83,4 и 166,8) → MDAtom (`--RunWaterAnalysis --DoNotUseRounding --scale 1.`) → геометрическая проверка → отбор по `0 ≤ n−#water ≤ 0,15` (операционный критерий, предварительный) → XYZ/CSV/Excel/графики. Смещения по мнимым модам исключены. Отклонённые структуры не удаляются бесследно. КЧ и радиусы измеряются у свободно оптимизированных геометрий, а не у ограниченных стартов.

**Проверки:** сохранение SHA256 входов, валидность 100 структур GWH, воспроизводимость случайных стартов, корректность состава Cs₁OₙH₂ₙ, полнота частот, наличие подтверждения сходимости, соответствие карт CoCoS/MDAtom/XYZ, устойчивость КЧ к порогам 0,05–0,30 и расстояниям Cs–O; устойчивость CoCoS к частоте критерия 83,4/125/166,8 см⁻¹, включая число групп и индекс Рэнда. Основное единичное значение — самая низкоэнергетическая подходящая структура; взвешивание электронными энергиями при 300 K только как дополнительная оценка. Не интерпретировать его как свободноэнергетическое распределение.

## 4. Выводы и нерешённые вопросы

До расчётов нельзя утверждать, какие n имеют устойчивые структуры с практически полной первой оболочкой. Чувствительность классификации к `--scale 1.` и порогу `n−КЧ ≤0,15` должна быть исследована на фактических геометриях. Вытянутые структуры с дробным КЧ около n−0,5 помечаются для независимой геометрической проверки; автоматически исключать их как физически невозможные нельзя. Повышение `--CritFreq` CoCoS само по себе не доказывает корректность разбиения. Статистическое усреднение по электронным энергиям не заменяет термодинамического ансамбля.
