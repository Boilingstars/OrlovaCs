## Главный вывод

При GFN2-xTB/ALPB(water) и заявленном пороге оболочки Cs⁺ держит **почти полную первую оболочку только при n = 4–7**. С n = 8 оболочка по MDAtom уже неполная (КЧ 7,4–7,8 при n = 8), хотя геометрически все O ещё ближе 4,0 Å. С n ≥ 9 ион уходит к **поверхности водяного кластера**: КЧ насыщается около 5–7, появляются контакты Cs–O > 4 Å и водородные связи вода–вода. Это согласуется с картиной большого катиона с низкой плотностью заряда, а не с «КЧ = n».

Порог 0,15 **не подгонялся** под желаемое КЧ. При n ≥ 8 даже ослабление до 0,30 не даёт полной оболочки, кроме пограничного хвоста n = 8/9.

## n = 4–7: замкнутая (или почти замкнутая) оболочка

Все проверенные минимумы имеют все контакты Cs–O ≤ 4,0 Å, водородных связей вода–вода нет, ориентация воды `cos(x) ≈ 1` (кислород к катиону).

**Представитель полной оболочки — минимум энергии среди прошедших фильтр** ([`analysis/lowest_energy_shell_model_per_n.csv`](analysis/lowest_energy_shell_model_per_n.csv)):

| n | структура | E / Ha | radius MDAtom / Å | cos(x) | #water |
|---|---|---:|---:|---:|---:|
| 4 | frame_0083 | −20,310085 | 3,612 | 1,000 | **4,0** |
| 5 | frame_0049 | −25,406230 | 3,729 | 1,000 | **4,9** |
| 6 | frame_0031 | −30,500725 | 3,836 | 0,999 | **5,9** |
| 7 | frame_0090 | −35,593793 | 3,941 | 0,999 | **6,9** |

Нюанс, важный для рукописи:

- При **n = 5** глобальный минимум уникальных структур имеет `#water = 4,5` и **не** проходит порог 0,15. Оболочечный представитель на 0,047 mEh выше (≪ kT).
- При **n = 7** глобальный минимум имеет `#water = 6,7` и тоже не проходит порог; оболочечный 6,9 почти вырожден (ΔE ≈ 0,004 mEh).
- Пример из задания подтверждён: **5,9 при n = 6 засчитывается**; 5,5 в этой серии как типичный случай n = 6 не встретился (минимум 5,7).

Размах электронных энергий внутри n = 4–7 — доли mEh, то есть набор практически вырожден. Больцмановское среднее только по E при 300 K ([`analysis/boltzmann_E_only_300K.csv`](analysis/boltzmann_E_only_300K.csv)) почти совпадает с оболочечным минимумом. Это **не** G(T): ZPVE / H / G не считались — термохимия Hessian не проверялась как источник свободных энергий.

Геометрия Cs–O (не КЧ MDAtom): полная координация по отсечке 3,6 Å есть у всех n = 4–6; у n = 7 — с 3,7–3,8 Å. Кристаллический старт 3,33 Å **не** равен равновесному ⟨Cs–O⟩ (3,33 → 3,65 Å к n = 7).

## n = 8: переходный состав

26 минимумов, КЧ MDAtom 7,4–7,8, **ни один** не проходит `n − CN ≤ 0,15` (нужно ≥ 7,85). При пороге 0,20 проходит 1 структура, при 0,30 — 12. Все 26 всё ещё имеют все Cs–O ≤ 4,0 Å (`surface` ≈ 0,02).

Это как раз класс «5,5 при n = 6» из задания: **пограничная геометрия, не автоматическое доказательство второй оболочки**. Вода ещё в первой сфере по расстоянию, но весовое `#water` не дотягивает до n. Нельзя ни объявить КЧ = 8, ни списать структуру как вторую оболочку.

## n = 9–14: поверхность и вторая сфера

С n = 9 картина ломается.

1. **КЧ больше не растёт с n.** Среднее `#water` 5,9 (n = 9) … 6,3 (n = 14). Глобальные минимумы: КЧ 5,2 / 5,4 / 5,6 / 5,4 / 6,2 / 6,8.
2. **Бимодальность n = 9.** Гистограмма распадается на семейство ~4,2–5,7 и хвост 8,2–8,7. Низкоэнергетический минимум — открытый (`surface` 0,21, 2 контакта > 4 Å, 5 H-связей вода–вода).
3. **Поверхностный Cs⁺.** `surface_index` 0,11 → 0,42. Для минимумов n = 10–14 типично 4–8 контактов Cs–O > 4 Å и 10–18 водородных связей в водяной «капле».
4. **Ориентация.** `cos(x)` падает с ~1,00 до ~0,44: часть молекул смотрит не на ион, а в сетку воды.
5. **Геометрическая полная оболочка Cs–O ≤ 4,0 Å:** n = 9 ещё 6 структур из 37; n ≥ 10 — ноль.
6. **Порог MDAtom 0,05–0,30:** для n ≥ 10 ноль структур на любом из этих порогов. Отсутствие «КЧ = n» здесь не артефакт выбранных 0,15.

Физическая интерпретация (в рамках GFN2-xTB/ALPB и данного поиска): дополнительная вода с n ≈ 9 идёт во **вторую сферу / водородно-связанный кластер**, а не достраивает первую оболочку крупного Cs⁺. Это не доказательство невозможности высококоординационных минимумов — только факт, что 100 GWH-стартов их не дали как частотно подтверждённые структуры, прошедшие фильтр.

## CoCoS: 83,4 / 125 / 166,8 см⁻¹

Рабочее значение — 125 см⁻¹, как проверяемый вариант вместо штатных 83,4. Число групп:

| n | 83,4 | **125** | 166,8 | ARI(83,4 vs 125) | ARI(166,8 vs 125) |
|---|---:|---:|---:|---:|---:|
| 4 | 1 | **2** | 2 | 0,00 | 1,00 |
| 5 | 2 | **3** | 8 | −0,06 | 0,01 |
| 6 | 2 | **3** | 5 | −0,14 | 0,28 |
| 7 | 5 | **7** | 11 | 0,16 | 0,02 |
| 8 | 5 | **9** | 10 | 0,18 | 0,51 |
| 9 | 33 | **34** | 35 | 0,86 | 0,80 |

Для n ≥ 10 три порога **совпадают**: каждая структура — своя группа (ARI = 1). Для n = 4–8 CritFreq меняет разбиение, и 125 нельзя объявлять «оптимальным» — только зафиксированным рабочим. Обратный порядок кадров при малых n даёт слабый/отрицательный adjusted Rand (почти вырожденный ландшафт).

## Что можно и нельзя говорить в рукописи

Можно:

- Cs⁺(H₂O)ₙ при GFN2-xTB/ALPB(water), 100 стартов: замкнутая/почти замкнутая первая оболочка для n = 4–7.
- Равновесный ⟨Cs–O⟩ растёт с n (~3,33 → ~4,12 Å по уникальным минимумам).
- С n ≥ 9 доминируют поверхностные структуры с КЧ ≈ 5–7 и сеткой H-связей; вторая сфера появляется как геометрический факт (Cs–O > 4 Å), не как подгонка порога.
- 125 см⁻¹ для CoCoS — проверяемый параметр; для n ≥ 10 группировка от него не зависит.

Нельзя без оговорок:

- сравнивать E(n) как энергию гидратации;
- выдавать больцмановские веса по E как населённости раствора;
- утверждать, что КЧ = n невозможно при n ≥ 8 — не найдено в **этом** поиске;
- считать поиск полным для n ≥ 9;
- переносить 3,33 Å в характеристику оболочки.

Пилот `smoke_3` (n = 4, 3 старта) на Linux воспроизвёл Windows-энергии до 7 знаков и те же седла; в сотню `full_100` не входит.
