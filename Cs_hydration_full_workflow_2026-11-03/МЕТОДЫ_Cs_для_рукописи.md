# Методы расчёта — Cs⁺(H₂O)ₙ

**Статус:** проект текста до получения и проверки настоящих результатов. Формулировки и численные сводки уточняются после расчётов.

## Генерация

Для гидратных кластеров Cs⁺(H₂O)ₙ (n = 4–14) планируется по 100 независимых стартов Glorious Water Hole (GWH) на стехиометрию, всего 1100. Молекулы воды располагаются по нормированным направлениям сферических упаковок, а их случайные ориентации генерируются по соглашению `zyz`. Начальный радиальный параметр опорных точек равен 3,33 Å (кристаллический ионный радиус Cs⁺ 1,81 Å для КЧ=6 по Шеннону плюс условный кислородный радиус 1,52 Å). Это **исходная геометрическая эвристика**, а не длина равновесной связи Cs–O. При оптимизации ориентаций используется исходное центрирование WaterCharges, GFN2-xTB/ALPB(water), заряд +1, мультиплетность 1.

## Свободная оптимизация и частоты

После генерации проводится свободная оптимизация геометрии с последующей дооптимизацией `tight`. Сходимость подтверждается по журналам xTB. Вычисляются матрица Гессе и внутренние колебательные частоты: для нелинейного кластера учитываются 3N−6 мод после исключения шести внешних степеней свободы. Структуры с подтверждёнными мнимыми внутренними модами исключаются из основного набора минимумов; смещения вдоль мнимых мод не выполняются. Слабые отрицательные частоты, потенциально вызванные численным шумом, отмечаются для отдельной проверки, но автоматически не признаются минимумами.

## Выделение локальных минимумов и характеристик

Для каждого n подтверждённые минимумы сортируются по энергии и сопоставляются CoCoS только после свободной релаксации, учитывая зеркально эквивалентные геометрии. Частота критерия структурного сходства CoCoS предварительно повышается с 83,4 до 125 см⁻¹; устойчивость группировки оценивается сравнением с 83,4 и 166,8 см⁻¹. Это параметр структурной кластеризации, а не частота нормальной моды. Утверждения об оптимальном значении допускаются только по результатам проверки. MDAtomLocalEnvironment применяется ко **всем** частотно проверенным структурам с `--RunWaterAnalysis --DoNotUseRounding --scale 1.`. Для каждого кадра из `local_surrounding_water_anlysis_*.res` извлекаются `radius[A]`, `cos(x)` и дробное `#water`, а энергия в Ha связывается с тем же свободно оптимизированным минимумом.

Операционная классификация полностью занятой первой оболочки для предварительного анализа: 

$$
0 \le n-\mathrm{CN}_{\mathrm{MDAtom}} \le 0{,}15.
$$

Этот порог использует величину `#water`, напечатанную с точностью одного десятичного знака, поэтому, например, 5,9 допускается для n=6; 5,5 остаётся пограничным геометрическим случаем и по этому порогу не проходит. Альтернативные пороги и геометрическая достоверность проверяются отдельно. Это не строго целочисленное КЧ и не универсальное физическое определение оболочки. При отборе внутри каждого CoCoS-кластера выбирается минимум энергии **среди геометрий, прошедших фильтр**. Остальные минимумы сохраняются в полном каталоге. Независимая проверка использует распределения Cs–O и ориентации воды без переноса анионных геометрических критериев.

Относительные электронные энергии рассчитываются внутри одного n:

$$
\Delta E_i(n)=E_i(n)-E_{\min}(n).
$$

Энергии разных стехиометрий не сравниваются напрямую как энергии гидратации. Для одной характеристики каждого n основной результат представляет самая низкоэнергетическая прошедшая структуру группы. Дополнительное усреднение по электронным энергиям при 300 K:

$$
p_i=\frac{\exp\!\left[-\frac{E_i-E_{\min}}{k_{\mathrm B}T}\right]}{\sum_j\exp\!\left[-\frac{E_j-E_{\min}}{k_{\mathrm B}T}\right]},\qquad
\langle A\rangle_E=\sum_i p_i A_i.
$$

Такое усреднение исследовательское: не учитывает энтропийные различия и вырождение групп. Расчёты с нулевыми колебательными поправками, энтальпиями или свободными энергиями могут быть проведены только после проверки термохимических данных, но **не подменяются** электронными энергиями.

## Представление результатов

Для n=4–14 планируются таблицы энергий, среднего радиуса Cs–O, ориентации воды, дробного КЧ и отбора полной оболочки; графики зависимостей от n и КЧ, анализ устойчивости к выбранным параметрам и насыщения по числу стартов. Отсутствие подходящей геометрии в конечной выборке не означает доказанной невозможности её существования.
